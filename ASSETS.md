# Assets — SOLARIS

All artwork and assets are stored locally and independently.

- `public/images/solaris-hero.webp`, `solaris-hero-mobile.webp`: original fictional architecture illustration generated with built-in ImageGen on 3 October 2026. Sculptural white concrete courtyard, curved roof and oculus, olive tree, blue sky and pool. No third-party photograph or client project. Generated by root agent for this commission.
- `public/images/solaris-interior.webp`, `solaris-interior-mobile.webp`: original fictional interior illustration generated with built-in ImageGen on 3 October 2026. Curved ash library shelving, blue sculptural chair and golden sunlight. Root agent generation. Used as architectural concept illustration; no built-project attribution.
- `public/fonts/manrope-latin.woff2`: independent local copy of the collection's verified Manrope Latin font. Google Fonts Manrope, SIL Open Font License 1.1. Licence accompanies it as `OFL-Manrope.txt`. This copy is project-local, not a runtime reference to another website.
- Pavilion meshes: original procedural geometry authored in `src/Pavilion.tsx`; no external model, texture or HDRI. RoomEnvironment from the installed MIT-licensed Three.js package creates the local lighting environment.
- Sunburst and interface marks: text glyphs/native CSS. No logo or external icon pack.

Images illustrate fictional studies and do not claim photographed built commissions. Project-specific images can be replaced through content.ts without changing layout.

Additional root-generated 3 October 2026 images: `solaris-cultural.webp` / `-mobile.webp` (Common Hours public pavilion and courtyard); `solaris-workspace.webp` / `-mobile.webp` (North Window creative workspace). Each named study now uses a different original generated concept illustration. No external image licensing applies. Project images use 768w/1536w responsive sources.

- Concrete and timber surface maps are original deterministic 512px canvas textures generated locally in Pavilion.tsx, used for roughness/bump and disposed with scene.
- `public/favicon.svg`: original ultramarine solar mark authored locally, no external icon source.

## Original Blender architectural worlds — 3 October 2026

| Delivery files in `public/images/` | Source composition |
| --- | --- |
| `solaris-world.webp`, `solaris-world-mobile.webp` | Wide view of the authored full-scale architectural world |
| `solaris-light-study.webp`, `solaris-light-study-mobile.webp` | Material/detail view of the same world |

These are locally rendered fictional Blender scenes. Geometry, placement, cameras and light composition are authored for this portfolio; photographed PBR maps and the environment are [Poly Haven CC0 assets](https://polyhaven.com/license), with the exact authors, download URLs and SHA-256 hashes in `assets/source/texture-manifest.json`. The editable packed source is `assets/source/architecture-world.blend`; project-local reconstruction tools and the used-asset attribution table are documented in [RENDERING.md](docs/RENDERING.md).

Settled throw geometry is preserved in `tools/worlds/cloth/solaris.json`, together with its recorded gravity/cloth-bake metadata. The editable simulation study is `assets/source/cloth-study.blend` and the reconstruction script is `tools/bake-cloth.py`. Cloth simulation is separate from CUDA image rendering. The external simulation cache is not included by this packaging step; the settled JSON and editable setup are included. See `docs/render/cloth.json` and the cache boundary in `docs/RENDERING.md`.

The final Cycles frames were rendered at 3200 × 2000 with CUDA GPU compute and OptiX denoising. Actual settings and machine-guard records are in `docs/render/`. Surface UV crops, recolouring and straight-through glass shadow transport are documented rendering adaptations. WebP encoding, website integration and browser/live verification are separate from source packaging. No claim of completed architecture, photographic capture or user acceptance is made. All earlier generated and licensed image provenance above remains applicable to those older files.
